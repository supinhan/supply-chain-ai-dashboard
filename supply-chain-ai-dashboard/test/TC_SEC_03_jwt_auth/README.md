# TC-SEC-03：基于角色的 JWT 鉴权逻辑测试

### 1. 测试流程
1. 验证签名算法完整性，基于 HS256 对头部、负载及秘钥进行加密，校验生成合法的加密 Token。
2. 权限隔离验证：
   *   生成管理员权限角色（admin），校验其通过并获取特权资源权限。
   *   生成低权限访客角色（guest），验证其直接被接口策略决绝并返回 False/拦截。
3. 时限效力验证：生成过期 Token（例如当前时间之前已过期），验证系统自动检测过期并强行拒签。
4. 执行 `test_jwt.py` 脚本：
   ```bash
   python test/TC_SEC_03_jwt_auth/test_jwt.py
   ```
