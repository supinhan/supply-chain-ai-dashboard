# TC-COMP-03：移动自适应与网络环境测试

### 1. 测试流程
1. **移动端自适应测试**：
   *   使用 Chrome 开发者工具模拟不同屏幕分辨率（如 iPad Pro、iPhone 14 Pro Max、常规 1080P/2K/4K 屏幕）。
   *   真机访问测试（iPhone 15 / 华为 Mate 60），校验两端下钻、收纳组件的手势和点击精度。
2. **网络环境测试**：
   *   在 Chrome 开发者工具 **Network** 面板中限制网络限速（模拟 3G、4G 及 50% 丢包的高延迟弱网环境）。
   *   检验系统在弱网下 WebSocket 握手失败、断线后，前端指数退避重连（1s、2s、4s、8s 等）的触发逻辑。

### 2. 测试结果
*   **状态**：**PASS**
*   **结果明细**：
    *   **大屏自适应布局**：使用 `flex` 与自适应 `vw`/`vh` 比例划分版面，图表容器使用 `resize` 监听进行尺寸重计算。移动端下，侧边抽屉组件和列表卡片自动缩放，无版面溢出或错位。
    *   **断网重连**：当测试中人为断开网络后，前端控制台显示 `WebSocket连接断开`，自动启动重连机制，并在 1s、2s、4s 后执行退避请求。一旦恢复网络，长连接成功自动复位，KPI 统计数据与告警重新无缝同步。
