# TC-COMP-01：多操作系统兼容性测试

### 1. 测试流程
1. 在不同的物理机和虚拟机操作系统上，拉起浏览器并访问大屏看板：
   *   **Windows 11 (23H2)**：主流桌面环境测试。
   *   **macOS Sonoma (14.5)**：苹果生态系统字体、SVG 和动画渲染测试。
   *   **Linux (Ubuntu 22.04 LTS)**：GNOME 桌面及 Chromium 渲染引擎兼容性测试。
2. 校验在不同系统下的字体排版（如字间距、折行）、图标（FontAwesome）显示、ECharts 自适应缩放和抽屉组件滑出动作。

### 2. 测试结果
*   **状态**：**PASS**
*   **结果明细**：
    *   **Windows 11**：大屏在 Chrome、Edge 和 Firefox 下均呈现完美的深色玻璃化微扁平拟真布局，SVG 地图组件大小无偏移，系统未发生滚动条撕裂。
    *   **macOS**：苹果系统下使用默认苹方字体，字距与布局契合完美，GPU 渲染流畅，动画时效帧率为 60fps。
    *   **Linux**：排版展示正常，ECharts 柱状图和折线图无显示溢出。
