# TC-PERF-01：响应延迟性能测试

### 1. 测试流程
1. 使用 Python 的 `requests` 库，分别循环发送 20 次请求至：
   *   订单流入接口：`POST /api/v1/stream/ingest`（携带 HMAC-SHA256 签名头部，测试包含双模 AI 风控判断的端到端时延）。
   *   未来销量预测接口：`GET /api/v1/forecast`（调用 AI 微服务回归预测，测试高频预测调取时延）。
2. 计算平均每次调用的耗时。
3. 执行 `test_latency.py` 脚本：
   ```bash
   python test/TC_PERF_01_latency/test_latency.py
   ```
