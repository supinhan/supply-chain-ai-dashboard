### 1. 测试流程
1. 连接本地 SQLite 数据库中的 `alerts` 告警表。
2. 检索表中是否存在状态为未处理（`status = 0`）的告警。

4. 重新查询该告警，断言其状态已被持久化更新为 1。
5. 运行 `test_alert_ack.py` 脚本：
